\# 🌐 Modern IoT \& Developer Portfolio



A high-performance, responsive portfolio website featuring a custom \*\*Canvas Particle System\*\*, \*\*Glassmorphism UI\*\*, and \*\*Dynamic Typing\*\* effects. Designed to showcase my projects in IoT, Web Development, and Computer Science.



!\[Portfolio Preview](https://img.shields.io/badge/Status-Live-success?style=for-the-badge)

!\[Tech](https://img.shields.io/badge/Built%20With-Tailwind%20CSS-blue?style=for-the-badge)



\## ✨ Key Features



\- \*\*Interactive Background:\*\* A custom-built JavaScript particle engine that reacts to the viewport.

\- \*\*Glassmorphism Design:\*\* Modern UI cards using `backdrop-filter` for a frosted-glass effect.

\- \*\*Project Gallery:\*\* Dynamically rendered project cards showcasing my work in IoT and Web.

\- \*\*Fully Responsive:\*\* Optimized for mobile, tablet, and desktop using Tailwind CSS.

\- \*\*Auto-Typing Hero:\*\* A smooth typing animation to introduce my profile.



\## 🛠️ Built With



\- \*\*HTML5 \& CSS3\*\* - Structural layout and custom glass styling.

\- \*\*Tailwind CSS\*\* - Utility-first styling for rapid, responsive design.

\- \*\*Vanilla JavaScript\*\* - Logic for the particle system, typing effects, and data rendering.

\- \*\*Lucide/FontAwesome\*\* - For professional iconography.
